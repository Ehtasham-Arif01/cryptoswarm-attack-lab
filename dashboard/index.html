Birthday attack: forging a signed contract

In a room of just 23 people, two share a birthday with 50% probability. The same math breaks hashes: an 34-bit hash has 17.2 G values, but a collision is expected after only about 146 k hashes (≈ √N).

1. Bob writes the fair contract ($100) and a fraud ($100,000) in 224 wordings each.
2. The swarm hashes both sets until a fair and a fraud wording have the same hash.
3. Alice signs the fair one. Her signature (made on the hash) also verifies on the fraud.

Cracking a leaked password table

A website's user table leaked: 12 usernames and their stored password hashes. The swarm tries common words × mangling rules (Dragon, sh4d0w, monkey2019, pepper123!…). How the site stored the passwords decides how long that takes.

Padding oracle: decrypting AES without the key

A web server gives users an AES-128-CBC encrypted session token. When a token comes back it decrypts it, and on bad padding it answers 500 padding error instead of 400 bad session. That one leaked bit is enough to decrypt the whole token.

CBC decryption: Pi = D(K, Ci) ⊕ Ci−1
1. Send X ‖ Ci with a chosen X instead of Ci−1.
2. Try 256 values of the last byte of X. The one without a padding error tells us that the last byte of D(K, Ci) ⊕ X = 0x01.
3. Repeat for every byte, right to left. Every block is attacked in parallel by the swarm.

Frequency analysis: breaking classical ciphers

English isn't random: E is 12.7% of letters, Z only 0.07%. Caesar and Vigenère keep that fingerprint, so the swarm never needs to brute-force the key:

1. Key length: for L = 1…16, split the text into L columns and measure the index of coincidence. English ≈ 0.066, random ≈ 0.038. One worker per L.
2. Columns: each column is a Caesar cipher. Try 26 shifts and keep the one whose letters match English best (χ²). One worker per column.

🔒 Fix: Encrypt-then-MAC

The fixed server appends HMAC-SHA256(IV ‖ C) to each token and checks it before decrypting (in constant time). Any tampered token gets the same 403 invalid session and is never decrypted, so there's no oracle. Authenticated modes such as AES-GCM give the same protection. TLS 1.3 removed CBC for this reason (POODLE, Lucky13).
